{% endblock %} {% block correct_answer %}A{% endblock %} {% block explanation %} Le modèle économique de ces "écosystèmes fermés" repose sur la collecte de données. Même si l'accès est gratuit, l'établissement paie en réalité avec les données de ses élèves, qui alimentent des profils publicitaires ou comportementaux. De plus, cela crée une accoutumance aux outils propriétaires, rendant une migration future très difficile et coûteuse (phénomène de "vendor lock-in"). {% endblock %}
