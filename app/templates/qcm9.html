{% extends 'qcm_base.html' %} {% block current_qcm %}9{% endblock %} {% block theme %}Thème 3 : Logiciels Libres et Choix Techniques{% endblock %} {% block question %}Quelle est la différence fondamentale entre un logiciel gratuit (freeware) et un logiciel libre (open source) ?{% endblock %} {% block options %}
A
Le logiciel gratuit est toujours sans publicité
B
Le logiciel libre permet d'accéder au code, de l'étudier et de le modifier
C
Le logiciel libre ne fonctionne que sur Linux
D
Le logiciel gratuit offre un support téléphonique 24/7
{% endblock %} {% block correct_answer %}B{% endblock %} {% block explanation %} La gratuité ne concerne que le prix (zéro euro). La "liberté" logicielle concerne les droits accordés à l'utilisateur : liberté d'exécuter le programme, d'étudier son fonctionnement (transparence), de le redistribuer et de l'améliorer. Pour un établissement public, cela garantit l'indépendance et la pérennité des outils, sans "boîte noire" opaque. {% endblock %}
